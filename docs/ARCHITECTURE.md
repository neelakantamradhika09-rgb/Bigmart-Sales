# BIGMART SALES – SYSTEM ARCHITECTURE

## 1. Project Overview

BigMart Sales Prediction is a Machine Learning
project that predicts product sales across outlets.

## 2. Dataset

Training Dataset: Train.csv

Testing Dataset: Test.csv

Target Column: Item_Outlet_Sales

Problem Type: Regression
